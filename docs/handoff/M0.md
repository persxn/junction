### 3.2 Engineering decisions with architectural weight

Recorded under "Minor decisions" in the WP handoffs; these are the ones worth your attention:

- **TypeScript 6.0.3, not 7.0.2** — typescript-eslint 8.70 supports `>=4.8.4 <6.1.0`. Revisit when it does.
- **Argon2id m=128 MiB, t=6, p=1** — 322–409 ms on this box. The pilot target is an 8 GB machine that
  may take 2–3× longer. WP-07a asked whether the wizard should calibrate instead; still unanswered.
- **scrypt work factor 18** for the passphrase-wrapped backup key (age's default, ≈256 MiB transient).
- **The setup gate sits before the session hook**, so a fresh install answers "not configured" rather
  than "not signed in". `/system/shutdown` is exempt so the tray can exit from inside the wizard.
- **`settings.ts` is the single typed registry** — one zod schema per key; no stringly-typed reads.
- **Shell preferences stay in `<dataDir>\shell-settings.json`** (R28), not in `settings`.
- **The F9 fallback is a hand-written prefix-locked GET proxy** in Rust, not `tauri-plugin-http`.
- **`seed:dev` survives** as a dev stopgap although WP-07b's wizard replaces it.
- **`smoke:bundle` was rewritten** in WP-07b: it used to prove the Argon2id addon with a 401 from
  `/auth/login`, which the R39 gate now answers 409. It completes the wizard instead.

### 3.3 Product-owner decisions taken in session — read this one

1. **Deployment shape (new information, 20 Sep 2026).** The owner states the product is a *standalone
   app: one professor, one machine, his own set of students.* No campus server, no LAN, no forwarded
   ports. This is **narrower than §3.1**, which says professors and admins "may share the machine" —
   the sentence that justifies accounts, roles, auto-lock and the lockout ladder. **Q1 is effectively
   answerable and §3.1 may need amending. Not changed: recorded for you.**
2. **Security posture reviewed and deliberately left as-is.** The owner asked why a local app was
   built this defensively. The split offered was: keep the loopback client secret, Host allowlist,
   `files.rs` path restriction and backup encryption; drop or dial down the Argon2id parameters, the
   R34 lockout ladder, the R35 audit hash chain, the unused R41 recovery code and the 15-minute
   auto-lock. **Their decision: no changes — proceed as specified.** Nothing was removed.
3. **Style instruction:** less security framing in prose, comments and reports. Describe what the code
   does rather than what attack it prevents. Applies from here on; existing comments were left alone.
4. **Q3 closed** — campus name and coordinates are collected at runtime by WP-07b's wizard.
