## 3. Bug found in WP-10 and fixed

**The event-type policy never hid anything after linking.** The resolver re-applied policies from the
resolved row, which stores the event type but not its confidence. WP-08b's policy hides only a
*confident* OTHER, so Unstop's quizzes (OTHER, 0.95) stayed VISIBLE. The resolver now passes the
confidence of the claim that won `eventType` (1 for an override).

## 4. Deviations

1. **`max_requests_per_run` is 12, not 11.** The listing is two queries (hackathons and competitions);
   the prompt's "1 listing page + ≤ 10 details" assumed one.
2. **Fixtures are synthetic and the capture is owed.** See above; the owner declined to use their own
   address for this dev machine.
3. **The proxy-cache bullet is not quoted verbatim** in `source-feasibility.md` §5. The Terms can't be
   fetched (SPA), and the prompt only paraphrases it. The owner's paste is requested there.
4. **The HTML fallback reads Angular's embedded server state** (`script#ng-state` / `#serverApp-state`).
   A client-rendered shell has none, and then the run fails `SCHEMA_CHANGED`, as step 6 requires. A
   fallback listing is never "complete" (§7.6), so the run is PARTIAL.

## 5. Minor decisions

- Types: `hackathons` → HACKATHON; subtypes such as coding → CODING_CONTEST, idea → IDEATHON; quiz, case
  study, cultural, workshop, conference, job fair, marketing, business, debate, essay and others →
  OTHER at 0.95, so they are hidden by policy.
- `isPaid: false` is known ₹0; `true` is unknown with the text kept; absent is unknown.
- Prizes: each line becomes text; a numeric total only when there is exactly one cash prize (never
  summed). Currency icons `fa-rupee`/`fa-dollar` map to INR/USD.
- The record URL comes from `public_url` only under `hackathons/` or `competitions/`; otherwise it is
  built from the id. It is stored, never followed.
- The timezone comes from the source default Asia/Kolkata; Unstop's timestamps carry +05:30, so they're
  exact.

## 6. Known issues

- **A redacted `mailto:` link renders as `[[contact details…]](mailto:[contact details…])`.** No
  personal data leaks, but WP-08a's redactor runs after Markdown conversion. Dropping `mailto:` links in
  the sanitizer would be cleaner (WP-08a code).
- WP-08a's phone heuristic matches URLs ending in `…-2026-1100001`. URLs are not redacted, so nothing
  breaks, but a prose mention of such a URL would be redacted.
- The detail endpoint `/api/public/competition/{id}` is a guess until the capture confirms it.
- `routes.test.ts`'s 1 MB body-limit test timed out once under load (seen before, in WP-09b).
