Deviations from the prompt (why):
- **Owner-directed scope (O-1…O-3):** rename to Junction + logo; M4 deferred so WP-33 ran first; a minimal slice of
  WP-31 pulled forward to publish an installer. The Assistant gradient sweep has no Assistant to apply to; the
  heading sweep is a gradient bar *under* page titles so text keeps its token colour.
- Appearance is stored as four registry keys whose values are maps keyed by user id (the registry has no per-user
  scope); unknown values fall back per field (`coerceAppearance`).
- Classic's `--ci-color-border-strong` moved #9aa3b2 → #848d9c: it measured 2.54:1, under the new 3:1 boundary
  check. Remapped, not exempted (R67) — the only visible change to Classic.
- Pausing applies to loops only: one-shot entrances start at opacity 0, and freezing them hid the KPI tiles and
  bar lists when content rendered in the tray (found on the built exe, fixed, now tested).

Minor decisions made:
- Chart series colours are new `--ci-series-1/2` tokens (blue/orange) validated for colour-blind separation;
  Catppuccin blue/mauve failed it. Single-series charts use one hue; values are always written as text.
- Months/weeks are Asia/Kolkata calendar months and Monday-start weeks; ranges follow A7, capped at 1 830 days.
- Funnel: competitions *created* in the range, counted at the furthest status reached; completion = COMPLETED ÷
  (all − withdrawn). Deadline-hit: stages due in range and past due; withdrawn/unselected competitions excluded.
- Milestones (first WINNER, 10th completion, four-week streak) are all-time facts, shown once per machine, never
  at CALM; marking happens on display.
- Packaged data folder is `%LOCALAPPDATA%\JunctionData` — `Junction` is where the per-user installer puts the
  program. The shell strips Windows' `\\?\` prefix from the resource dir (Node cannot start from it).
- `vcruntime140(_1).dll` ship app-local: the prebuilt argon2 addon needs them; a clean Windows may not have them.

New dependencies (name@version — why):
