Deviations from the prompt (why):
- Error codes are `AUTH_GUEST_HAS_NO_PASSWORD`, `AUTH_GUEST_UNAVAILABLE`, `AUTH_ROLE_NOT_FOR_MODE`,
  `AUTH_SINGLE_PROFILE_INSTALL`: R12's domain-prefix rule (errors-domains test) — the prompt's names had none.
- `auth.guestEnabled` setting dropped: the guest account's ACTIVE/DISABLED status is the single truth.
- The audience question and "Myself/An institution" share one screen, so Myself is 4 wizard screens.
- Migration is 0033 (0032 = v0.9.1 hotfix). Rebuilds use `defer_foreign_keys` + re-insert into the final table, since
  `PRAGMA foreign_keys=OFF` is a no-op inside drizzle's transaction.
- "This is me" is on the create form only (StudentDetail does not say who is linked); the Dashboard's "Mine" already
  means "competitions I own" for a student, so it does not read the link.
- No backup job exists yet (WP-28), so "backups not set up" needed no code; a student install writes no backup key.

Minor decisions made:

- Place picker = gazetteer prefix on ASCII name (37 k rows, scan) + institutions with coordinates; typed coordinates
